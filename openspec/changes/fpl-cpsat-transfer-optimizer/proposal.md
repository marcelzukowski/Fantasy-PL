# Proposal

## Why
The stable approximate V3 search is deliberately limited to K<=2. The K<=5 portfolio failed a
required reduced oracle by8.271, so a future exact-model feasibility study needs objective and
proof boundaries before implementation. Phase1 is now authorized: an isolated exact legal-package
generator with a declared linear projection surrogate, not a complete strategic V3 solver.

## What Changes
- Implement simultaneous K0..5 final rosters with independent allocation of up to five packages/K.
- Verify native legality/FT/hits, exact scaled-surrogate oracles and frozen GW8 results.
- Report deterministic settings, time limits, statuses, bounds and scaling error.
- Retain the incumbent as independent evidence; no production integration or new beam heuristic.

## Capabilities
### New Capabilities
- `cpsat-transfer-research`: a future isolated solver experiment with auditable mathematical scope.

### Modified Capabilities
None. The stable V3 baseline is unchanged.

## Impact
Development scripts/tests execute CP-SAT only in an external `.venv-solver` JSON worker.
OR-Tools is isolated in `.venv-solver` because its protobuf requirement conflicts with `.venv`.
No GUI import, runtime dependency, V22, report schema, packaging, account write or provider call.
Phase2 full V3 evaluation, multi-GW optimization and production promotion require new explicit tasks.
This change is not automatically archived.

## Authorized Phase2 extension
Compare diagnostic A top5/K, B top10/K and C top5+5 structurally diverse/K. Apply each current
K0..5 package atomically and evaluate the existing complete V3 objective with native future K<=2,
horizon3, beam40 and terminal FT valuation. Independently preserve the production incumbent.
Use exact-context shared caches, a versioned integrity-checked JSON worker and a bounded GW8
experiment. Report natural reference recall and approximation limits; do not integrate production.

## Authorized Phase2B final bounded recall experiment
Use up to3 previously V3-evaluated K2 anchors to generate simultaneous K3..5 neighborhoods.
Retain incoming strengths while varying funding OUT players, extensions and positional upgrades.
Rank using anchor V3 values, native optimized-XI HOLD-suffix path values and structural diversity,
not the surrogate alone. Evaluate at most12 new packages through unchanged full V3 in120s.
Verify exact-context Phase2 cache reuse, independent reference reconstruction and six reduced
oracle contexts. Missing optima and latency explicitly determine GO/NO-GO; no production integration.
